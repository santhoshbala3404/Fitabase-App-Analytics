# Fitness Data Analytics Project

## Project Overview

This project focuses on analyzing fitness tracker data from Fitabase to understand users' physical activity patterns, health indicators, and lifestyle habits.

The analysis is performed using three different tools: **SQL, Python (Pandas), and Power BI**.

The project aims to uncover meaningful insights from fitness data, including daily steps, calories burned, activity intensity, heart rate, sleep patterns, and BMI.

## Tools & Technologies
- **SQL:** Data querying and analysis.
- **Python (Pandas):** Data cleaning, preprocessing, exploratory data analysis, and visualization.
- **Power BI:** Interactive dashboards and visual representation of insights.

## Key Areas of Analysis
- Daily activity and step count analysis.
- Calories burned and distance covered.
- Sedentary and active behavior patterns.
- Heart rate analysis.
- Sleep duration and sleep efficiency.
- BMI and weight trends.

## Project Objective

To transform raw fitness data into meaningful insights that help identify user behavior, understand fitness trends, and suggest opportunities for improving physical activity and overall well-being.
